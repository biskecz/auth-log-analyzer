# Auth Log Analyzer

A simple Python project that analyzes authentication logs.

## Features

- Counts successful logins
- Counts failed logins
- Finds suspicious IP addresses
- Detects possible brute-force attacks
- Lists unique IP addresses
- Sorts failed login attempts by IP

## Technologies

- Python 3
- Dictionaries
- Sets
- Loops
- File handling

## Sample Log Data

The `auth.log` file contains fictional sample authentication logs created for testing and demonstration purposes.

It does not contain real user data or real authentication logs.

## Run

Make sure `auth.log` is in the same directory as the Python script.

```bash
python3 auth_log_analyzer.py
